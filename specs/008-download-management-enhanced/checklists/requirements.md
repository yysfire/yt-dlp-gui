# Quality Checklist: 下载管理增强

**Feature**: 008-download-management-enhanced
**Phase**: P1 Enhancement
**Last Updated**: 2026-05-31

## 需求完整性检查

- [ ] 所有用户故事都有 Given/When/Then 验收场景
- [ ] 每个用户故事都定义了独立测试方法
- [ ] 所有边缘情况都已记录（HTTP 4xx 不重试、文件缺失检测、代理认证等）
- [ ] 功能需求（FR）覆盖所有用户故事中的能力描述
- [ ] 非功能需求（成功率提升 20%、限速偏差 < 10%）在 Success Criteria 中可度量
- [ ] 关键实体（RetryConfig、ProxyConfig、DownloadMode）已定义
- [ ] 下载模式与重复检测的交互逻辑已明确

## 技术可行性检查

- [ ] `--limit-rate` 参数格式与 yt-dlp 文档确认一致
- [ ] `--proxy` 参数支持 SOCKS5、HTTP、HTTPS 三种协议
- [ ] `bestaudio[ext=xxx]` 格式选择器语法正确
- [ ] 代理 URL 编码正确处理特殊字符（RFC 3986）
- [ ] 下载记录 JSON 结构已包含 quality、format 字段（或需扩展）
- [ ] 文件存在性检查的性能影响可接受（大量文件时）

## 用户体验检查

- [ ] 重复检测结果状态在 UI 中用不同图标/颜色区分
- [ ] "可升级下载"有明确的用户操作入口（非自动下载）
- [ ] 重试过程在 UI 中显示当前重试次数和下次重试时间
- [ ] 下载失败后的错误信息区分网络错误和代理错误
- [ ] 限速输入框有单位提示（KB/s）和常用预设值（512、1024、2048、无限制）
- [ ] 音频下载模式在订阅列表中显示图标标识
- [ ] 代理配置表单有"测试连接"按钮

## 兼容性与边界检查

- [ ] 代理 URL 格式校验覆盖常见错误格式
- [ ] 限速值校验拒绝负数、非数字、超范围值
- [ ] 下载模式切换后历史记录不受影响
- [ ] 文件缺失检测在 Windows/macOS/Linux 三种文件系统上正确
- [ ] 重试时网络完全断开的情况下系统不无限等候

## 安全性检查

- [ ] 代理密码在配置文件中不应明文存储（至少 Base64 编码）
- [ ] 代理 URL 不包含在 UI 错误信息中完整展示（避免泄露）
- [ ] 限速参数值经过范围校验，防止极端值导致 yt-dlp 异常

## 测试覆盖检查

- [ ] 重复检测单元测试覆盖：同 ID 同画质、同 ID 不同画质、不同 ID 同标题、文件缺失
- [ ] 重试逻辑单元测试覆盖：网络错误重试、404 不重试、403 不重试、最大次数上限
- [ ] 限速参数生成单元测试覆盖：正常值、0 值、负数值
- [ ] 代理 URL 构建单元测试覆盖：无认证、有认证、特殊字符密码
- [ ] 音频格式选择器单元测试覆盖：m4a、mp3、opus、aac、无独立流回退

## 依赖与集成检查

- [ ] 与 `services/ytdlp.rs` 的命令构建逻辑兼容
- [ ] 与 `commands/download.rs` 的 `check_and_download()` 流程集成
- [ ] 与 `models/download.rs` 的 DownloadRecord 结构体扩展兼容
- [ ] 与 `models/settings.rs` 的 AppSettings 新增字段协调
- [ ] 与前端 `src/lib/tauri.ts` 新增命令的 invoke 调用一致
