## 插件系统框架

- [ ] CHK-001 插件加载器：支持从指定目录扫描和加载插件包
- [ ] CHK-002 插件清单解析：解析 plugin.json/manifest 获取元数据和权限声明
- [ ] CHK-003 插件沙箱运行时：实现 WebAssembly 或受限 JS 运行时
- [ ] CHK-004 权限系统：定义权限级别（文件读、文件写、网络、通知）并按声明确认
- [ ] CHK-005 插件钩子系统：注册 pre_download、post_download、on_subscription_added 等钩子
- [ ] CHK-006 UI 扩展点：插件可注册自定义面板、菜单项、设置页
- [ ] CHK-007 插件生命周期管理：安装 → 启用 → 运行 → 暂停 → 禁用 → 卸载
- [ ] CHK-008 插件冲突检测：加载时检查依赖兼容性和已知冲突
- [ ] CHK-009 插件资源监控：监控 CPU、内存使用，超限时告警或自动暂停
- [ ] CHK-010 插件错误隔离：单个插件崩溃不影响主程序和其他插件
- [ ] CHK-011 插件数字签名验证：安装时验证插件包的签名
- [ ] CHK-012 插件管理 UI：列表展示、启用/禁用开关、卸载按钮、详情面板

## API 接口开放

- [ ] CHK-013 本地 HTTP 服务启动：在 localhost:9380 启动 REST API 服务
- [ ] CHK-014 API 认证中间件：基于 Token 的请求认证
- [ ] CHK-015 Token 管理 API：创建、列表、删除、刷新 Token
- [ ] CHK-016 订阅管理 API：POST /api/subscriptions、DELETE /api/subscriptions/:id、GET /api/subscriptions
- [ ] CHK-017 下载控制 API：POST /api/subscriptions/:id/check、POST /api/check-all
- [ ] CHK-018 下载记录 API：GET /api/records、GET /api/records/:id
- [ ] CHK-019 设置管理 API：GET /api/settings、PUT /api/settings
- [ ] CHK-020 系统状态 API：GET /api/status（运行状态、yt-dlp 版本、磁盘空间）
- [ ] CHK-021 API 请求限流：防止恶意高频请求
- [ ] CHK-022 API 错误响应标准化：统一的错误码和消息格式
- [ ] CHK-023 OpenAPI 3.0 文档自动生成：GET /api/docs 返回 swagger JSON
- [ ] CHK-024 API 日志记录：所有请求记录到日志文件（不含敏感信息）
- [ ] CHK-025 API 服务端口可配置：settings 中可更改默认端口
