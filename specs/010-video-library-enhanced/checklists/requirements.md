# Quality Checklist: 视频库增强

**Feature**: 010-video-library-enhanced
**Phase**: P1 Enhancement
**Last Updated**: 2026-05-31

## 需求完整性检查

- [ ] 所有用户故事都有 Given/When/Then 验收场景
- [ ] 每个用户故事都定义了独立测试方法
- [ ] 所有边缘情况都已记录（空搜索结果、元数据缺失、跨年分组等）
- [ ] 功能需求（FR）覆盖所有用户故事中的能力描述
- [ ] 非功能需求（搜索响应、删除速度、元数据成功率）在 Success Criteria 中可度量
- [ ] 关键实体（DownloadRecord 扩展、SearchFilter、GroupByMode）已定义
- [ ] 播放计数与文件打开操作的关联已明确

## 技术可行性检查

- [ ] 前端本地过滤在 5000+ 条记录时的性能已验证
- [ ] 下载记录 JSON 扩展字段与现有数据向后兼容
- [ ] 视频元数据提取不显著延长下载完成后的处理时间
- [ ] 批量删除的文件操作在异步 task 中执行，不阻塞主线程
- [ ] 日期分组逻辑正确处理时区差异

## 用户体验检查

- [ ] 搜索栏有占位符提示文字"搜索标题或频道名"
- [ ] 筛选条件以标签（Chip）形式显示，支持单个移除
- [ ] 多选模式有明显的视觉反馈（复选框 + 高亮行）
- [ ] 批量删除确认对话框显示受影响数量和总文件大小
- [ ] 空搜索结果有明确的"无结果"提示和操作建议
- [ ] 播放次数过高时显示为 "1.2k" 等缩略格式
- [ ] 详情面板的元数据信息有合理的分组和排版

## 兼容性与边界检查

- [ ] 旧记录无新增元数据字段时正确处理默认值
- [ ] 文件大小超过 4GB 时正确显示（不溢出）
- [ ] 日期分组跨年时正确显示年份
- [ ] 搜索框输入极长字符串（500+ 字符）不导致布局破坏
- [ ] 播放计数为 null/undefined 时显示"0 次"

## 安全性检查

- [ ] 搜索输入不用于构造命令或 SQL（防止注入）
- [ ] 批量删除确认防止误操作

## 测试覆盖检查

- [ ] 高级搜索单元测试覆盖单条件、多条件 AND、正则特殊字符、空输入
- [ ] 视频信息提取单元测试覆盖正常元数据、部分缺失、全部缺失
- [ ] 批量删除单元测试覆盖正常删除、文件缺失、部分失败
- [ ] 分类筛选单元测试覆盖各平台、画质、日期范围
- [ ] 播放计数单元测试覆盖递增、重置、并发访问
- [ ] 前端筛选组件测试覆盖实时过滤、高亮、分页

## 依赖与集成检查

- [ ] 与 `useDownloadRecords()` Hook 的接口兼容性
- [ ] 与 `DownloadRecordList.tsx` 组件的数据传递兼容
- [ ] 与 `DownloadRecordItem.tsx` 组件的新字段显示兼容
- [ ] 与 download_records.json 的读写兼容
- [ ] 与 `tauri::api::shell::open` 调用播放计数更新集成
