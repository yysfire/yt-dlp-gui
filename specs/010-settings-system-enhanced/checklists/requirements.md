# Quality Checklist: 设置系统增强

**Feature**: 010-settings-system-enhanced
**Phase**: P1 Enhancement
**Last Updated**: 2026-05-31

## 需求完整性检查

- [ ] 所有用户故事都有 Given/When/Then 验收场景
- [ ] 每个用户故事都定义了独立测试方法
- [ ] 所有边缘情况都已记录（覆盖优先级、预设删除、快捷键冲突等）
- [ ] 功能需求（FR）覆盖所有用户故事中的能力描述
- [ ] 非功能需求（主题切换速度、快捷键延迟）在 Success Criteria 中可度量
- [ ] 关键实体（SubscriptionOverrides、QualityPreset、ThemeConfig、Keybinding）已定义
- [ ] 覆盖优先级逻辑（订阅级 > 全局）已明确

## 技术可行性检查

- [ ] 订阅 JSON 序列化中 overrides 字段与现有结构向后兼容
- [ ] yt-dlp 格式选择器字符串语法白名单验证逻辑已设计
- [ ] MUI ThemeProvider 动态主题切换不引起组件卸载重新挂载
- [ ] 快捷键冲突检测算法正确处理不同修饰键组合
- [ ] 音频格式选择器 `bestaudio[ext=xxx]` 在所有支持的平台上有效

## 用户体验检查

- [ ] 订阅编辑面板中覆盖参数有"与全局相同"的默认显示
- [ ] 质量预设列表支持拖拽排序
- [ ] 音频格式选择器有格式说明（如"m4a — 最佳兼容性"）
- [ ] 主题切换有即时预览，不等用户关闭设置
- [ ] 快捷键配置表格清晰展示操作名称、当前快捷键、冲突状态
- [ ] 强调色选择器预览在所有 UI 元素上的效果

## 兼容性与边界检查

- [ ] 覆盖参数为 null 时正确回退到全局设置
- [ ] 自定义预设被删除后使用该预设的订阅回退到全局默认
- [ ] 主题跟随系统模式在 macOS/Linux/Windows 行为一致
- [ ] 快捷键修改保存后立即生效
- [ ] 质量预设名称不可为空或仅空白

## 安全性检查

- [ ] 格式选择器字符串不用于命令注入（只做白名单校验后传递）
- [ ] 自定义主题色值经过 CSS 验证防止 XSS

## 测试覆盖检查

- [ ] 参数覆盖解析单元测试覆盖：有覆盖、无覆盖、多字段覆盖、部分覆盖
- [ ] 质量预设格式选择器生成测试覆盖所有预定义预设
- [ ] 音频格式选择器测试覆盖所有格式选项
- [ ] 主题切换单元测试覆盖三种模式
- [ ] 快捷键冲突检测单元测试覆盖无冲突、单键冲突、组合键冲突

## 依赖与集成检查

- [ ] 与 `models/subscription.rs` 的 Subscription 结构体扩展兼容
- [ ] 与 `models/settings.rs` 的 AppSettings 新增字段协调
- [ ] 与 `services/ytdlp.rs` 的画质预设映射逻辑兼容
- [ ] 与 `App.tsx` 的 ThemeProvider 集成
- [ ] 与 `SettingsDialog.tsx` 的设置页 UI 组件集成
- [ ] 与 `src/lib/tauri.ts` 的新增/变更命令一致
