## 多用户支持

- [ ] CHK-001 应用启动用户选择：启动时显示用户选择界面
- [ ] CHK-002 用户配置文件创建：用户名、密码（可选）、下载目录
- [ ] CHK-003 用户切换：无需重启应用，快捷切换当前用户
- [ ] CHK-004 用户数据隔离：每个用户独立的 subscriptions、records、settings
- [ ] CHK-005 共享数据目录：团队级别的共享订阅和下载记录存储
- [ ] CHK-006 团队创建：管理员创建团队，生成团队 ID 和邀请码
- [ ] CHK-007 成员邀请：通过邀请码加入团队
- [ ] CHK-008 成员列表管理：查看、移除、修改成员角色
- [ ] CHK-009 共享订阅源管理：团队订阅的增删改查
- [ ] CHK-010 私有订阅源管理：个人订阅与团队订阅分开显示
- [ ] CHK-011 LDAP/AD 集成接口：预留用户导入接口

## 权限管理

- [ ] CHK-012 角色定义：管理员、编辑者、查看者三种预定义角色
- [ ] CHK-013 权限矩阵：资源（订阅/设置/下载/用户）× 操作（CRUD）矩阵
- [ ] CHK-014 管理员功能集：团队管理、角色分配、审计日志、集中管理
- [ ] CHK-015 编辑者功能集：订阅管理、下载操作、个人设置
- [ ] CHK-016 查看者功能集：只读查看所有数据，无修改权限
- [ ] CHK-017 自定义角色创建：管理员可创建自定义角色和权限组合
- [ ] CHK-018 权限检查中间件：所有操作执行前检查权限
- [ ] CHK-019 权限不足提示 UI：清晰的权限不足提示和原因说明
- [ ] CHK-020 权限变更即时生效：修改角色后无需重新登录
- [ ] CHK-021 权限继承：团队成员角色可被团队管理员覆盖
- [ ] CHK-022 权限 UI 适配：根据角色显示/隐藏功能按钮

- [ ] CHK-025 操作类型覆盖：增删改查订阅、触发下载、修改设置、用户管理
- [ ] CHK-026 审计日志查询 UI：按时间、用户、操作类型筛选
- [ ] CHK-027 日志分页：大量日志的分页加载
