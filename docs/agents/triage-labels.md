# Triage 标签

各技能以五个规范 triage 角色沟通。本文件把这些角色映射到本仓库 issue 跟踪器中实际使用的标签串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义                             |
| -------------------------- | -------------------- | -------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需评估此 issue             |
| `needs-info`               | `needs-info`         | 等待报告者补充信息               |
| `ready-for-agent`          | `ready-for-agent`    | 已完整描述，可由 AFK agent 处理  |
| `ready-for-human`          | `ready-for-human`    | 需人工实现                       |
| `wontfix`                  | `wontfix`            | 不予处理                         |

当某项技能提到某个角色（如「apply the AFK-ready triage label」），使用上表中对应的标签串。

若实际使用其它命名，改右列即可。
